# 童健云开源路线图

| 阶段 | 目标 | 验收方式 |
|---|---|---|
| 首个膳食与食堂公开版本 | 一条可复现的试用流程，以及安装、升级、测试和问题反馈入口 | 园长用虚构数据看完一周业务，技术人员按文档搭起独立站点 |
| 外部园所试用 | 邀请两到三家园所，各走一遍周食谱、采购验收和日结，先解决影响重复使用的问题 | 记录从试用到完成首周所需时间、卡点及改进结果 |
| 降低维护成本 | 根据试用重点补齐常用角色覆盖、故障排查和版本维护说明 | 管理员能独立完成升级、恢复和业务数据导出 |

功能建议可提交到 [GitHub Issues](https://github.com/jerry317395616/tongjianyun/issues)。复现案例请使用虚构数据。
