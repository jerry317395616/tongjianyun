# 工作台学生名单上传

入口：业务工作台工具栏“上传学生名单”。仅当前账号私有文件，支持 XLSX / XLS / CSV，5 MB、2000名、60列上限。无需新增 DocType。

1. 选择文件。可为无班级记录指定已有班级，或勾选年龄分班建议。
2. 后台读取多工作表、标题行、重复表头、显式合并单元格。规则无法识别时复用受限源码 Codex 客户端，只提供筛选后的表头标签，不提供学生明细。最多4个复杂工作表调用模型。
3. 预览新增、加入班级、保持不变、待核对记录，显示工作表/行号和识别依据。
4. 点击确认，仅写入预览中通过核对的记录；写入前再次核对权限、文件内容、学生身份和班级。整批事务失败全部回滚。

已有学生不覆盖；不转班、不停用、不删除、不创建班级、不创建登录账号。系统编号和身份证优先核对；仅姓名不能合并，姓名+完整生日唯一匹配才保留已有档案。信息冲突待核对。班级缺失不猜测；年龄建议需用户勾选并在预览确认，按当前学年9月1日满3/4/5—6岁对应已有小/中/大班。原文件漏掉的学生不受影响。

任务缓存保留一小时，仅发起账号可读取；关闭窗口后再次点击入口可恢复本浏览器该账号的任务。成功摘要写入私有源文件评论。失败时修正原表重新上传；不会根据前端传入的任意学生值直接写库。

限制：图片、扫描件、年龄代替生日、无法可靠定位的多行表头需要整理原文件。本入口不提供已有档案覆盖操作。预览不代表写入成功，最终以完成状态为准。

测试：`python -m unittest tongjianyun.tests.test_student_roster_upload tongjianyun.tests.test_codex_ingredient_client`。部署后清站点缓存即可载入工作台入口，不执行 migrate。
