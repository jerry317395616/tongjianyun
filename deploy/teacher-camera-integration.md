# 教师刷脸考勤接入：离线准备阶段

设备：DS-2CD3646FWDA3/F-LZS(2.7-12mm)。尚未联网，未验证事件格式或人脸比对能力。

## 本次代码

`tongjianyun.camera_preflight.probe` 是内部只读连通性检查，不是公共 API。
检查设备型号、固件、能力接口响应及设备时间；Digest 认证、证书校验、禁止重定向、限制返回大小。
凭据由部署人员通过私密配置注入内存，不放进 URL、命令行、日志或 Git。
摄像头仅通过私网/VPN访问；需要配置受信的 HTTPS 证书。没有自动修改摄像头设置。

## 目标流程（尚未实现）

摄像头抓拍 → 远端服务器识别 → 仅匹配已同意的在职教师名册 → 时间/质量/多人歧义检查
→ 幂等签到事件 → 教师可查看、更正 → 考勤汇总。

抓拍不等于身份识别，识别不等于完整出勤；单一机位不能凭最后出现时间认定签退。
不使用通用大模型根据外貌猜姓名，不自动判定缺勤或扣薪。
人脸模板与照片必须私有存储、限制访问并设保留期限；不建立儿童或访客人脸库。
未同意、未知、低置信度以及存在歧义的结果不写正式考勤，提供非刷脸替代入口。

## 上线前必须完成

1. 摄像头接入网络，提供VPN可达私网地址，校准设备时间。
2. 核验真实固件能力并获取脱敏的抓拍事件样本，开发事件订阅与断线恢复。
3. 核验教师—员工映射；选择正式打卡存储模块。当前源码只有 Instructor/Employee，未发现 Employee Checkin/Attendance。
4. 取得教师同意后注册照片，选定可合法部署的识别模型与活体/防重放策略。
5. 用实际入口样本校准阈值，做重复、离职、未知人、多人、断网、补传与撤回同意测试。
6. 开发考勤页面和写入业务服务，再灰度试运行；不能把本次预检组件视为已完成刷脸考勤。
