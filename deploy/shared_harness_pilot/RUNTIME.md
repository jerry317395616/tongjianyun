# 单实例切换前检查与候选配置

当前正式实例监听 13090，加载 native-bench-business 策略；其 ALLOWED_TOOLS 不含 employee_frappe_read。因此不能直接追加共享接口，也不能在维护会话目录上移除旧策略。runtime.conf 候选使用独立 DSH_HOME，只加载 employee-readonly、employee-shared 和本目录 runtime.yml；仍占用同一个 13090，不启动第二个实例。维护目录不迁移、不删除。

模型沿用现有 Qwen endpoint 和 QWEN_API_KEY 环境变量名，不读取或复制密钥。候选模型请求上限保守设为 1024 输出 token、8192 上下文，不是修改模型服务的最大上下文。最终真实模型请求仍需验收。基础 ui-settings 服务保留，设置管理页面保持禁用。

此文件及 runtime.conf 只是候选，尚未安装 systemd drop-in，也未切换公共代理。切换须同时阻止公共 Host API；候选不发布管理员启动票据，因此不能继续使用旧网关。先检查 QWEN_API_KEY 是否由服务环境提供（只检查可用性，不能打印），再安装专用静态路径和员工 API 白名单代理，最后在同一个服务上切换。失败时恢复旧 drop-in 与代理，旧会话目录保持原状。
